# ZEI 231 — marketplace dei plugin

Marketplace di Claude Code per [ZEI 231](https://zei.services), il gestionale del Modello 231 (D.Lgs. 231/2001).

```
/plugin marketplace add ZEI-231/zei231-plugin
/plugin install zei231-registro@zei231
```

Il plugin `zei231-registro` porta quattro skill sul Modello 231 e il collegamento all'MCP di ZEI 231. Scrivi «Voglio creare un modello 231»: ZEI crea il gruppo della tua società, mostra il profilo, le attività sensibili del processo Amministrazione con le famiglie di reato e i protocolli proposti, e apre la richiesta di preventivo al consulente partner CO.DE. Dettagli in [zei231-registro/README.md](zei231-registro/README.md) e nella [guida](https://zei.services/guida).
